Visualizations

Each visualization is created with a constructor, refined with fluent methods, and added to an Image.

LaTeX math is supported in every label. Use a single backslash in .asy strings — "$\land$", not "$\\land$".

Every visualization also implements the same render(width, height, unit) contract, laying itself out to fill whatever area it is given.

  • RelationDiagram

    Functions, relations, and mappings between sets.

  • TruthTable

    Truth tables generated from evaluator functions.

  • AccumulationTable

    An iterative accumulation, one row per step.

  • Plot

    Continuous function graphs — explicit and implicit, on one set of axes.

  • DiscretePlot

    Step and bar plots for Riemann sums and discrete accumulation.
