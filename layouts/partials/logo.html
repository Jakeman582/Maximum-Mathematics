{{- /* Overrides the theme's own layouts/partials/logo.html (a project-level file at the same path takes precedence over the theme's — standard Hugo layout lookup, not a hook the theme provides specifically for this). While browsing inside a book — the book's own page, or any of its descendants — this replaces the site title/logo with that book's cover, shown full-bleed behind the header as a hero image (see assets/css/maximum-mathematics.css, ".mm-book-cover-logo"), linking back to the book's own landing page. No title text renders over the image — the main sidebar tree names the book instead, once it's showing that book's own table of contents rather than the whole site (see the `cascade.params. sidebarmenus` block in the book's own _index.md). Everywhere else, if assets/images/logo.png exists, that renders full-bleed the same way (".mm-site-logo") in place of the plain brand gradient. That same file is also picked up automatically as the site favicon by the theme's own auto-favicon.html — nothing to wire up for that separately. Only falls through to the theme's original auto-logo.html (the plain site title on the gradient) if no logo.png exists. A book sets its cover via front matter: [params] cover = 'my-book-cover.png' # filename only, resolved against # assets/images/book-covers/ */ -}} {{- $page := . -}} {{- $coverPage := partial "_mm/book-page.html" $page -}} {{- if $coverPage -}} {{- $coverPath := printf "images/book-covers/%s" $coverPage.Params.cover -}} {{- $cover := resources.Get $coverPath -}} {{- if not $cover -}} {{- errorf "logo.html: %q (from %q) has no matching file in assets/images/book-covers/" $coverPage.Params.cover $coverPage.File.Path -}} {{- end -}} {{- $coverImage := $cover.Resize "800x800" -}} {{- /* The photo needs to reach #R-homelinks too, a sibling of the element this partial renders into (#R-header-wrapper) — out of reach for a plain , so it's set as a CSS custom property on their shared ancestor instead, and painted as a background in maximum-mathematics.css. */ -}} {{- else -}} {{- $siteLogo := resources.Get "images/logo.png" -}} {{- if $siteLogo -}} {{- $logoImage := $siteLogo.Resize "800x800" -}} {{- else -}} {{- partial "auto-logo.html" site.Home -}} {{- end -}} {{- end -}}
